# جفتینو 🌼
بازی جفت‌کارت فارسی (PWA): نصب‌شدنی، آفلاین، بدون سرور. ساخته‌ی فاطمه کدخدایی.

## پوشه‌ها
- `index.html`، `style.css`، `app.js`: خود اپ (کامنت‌های فارسی دارند). رنگ‌ها بالای `style.css` هستند.
- `data/`: `animals.json` و `fruits.json` (کارت‌ها)، `levels-config.json` (شبکه‌ها، زمان، جابه‌جایی کارت‌ها، ستاره‌ها، نقطه‌های مرحله روی نقشه)، `about.json` (صفحه‌ی درباره‌ی من).
- `images/`، `icons/`: تصویرها و آیکون‌ها. `fonts/`: خالی است (فونت پیش‌فرض گوشی استفاده می‌شود).
- `manifest.json`، `service-worker.js`: برای نصب و کار کردن آفلاین. `design/`: خلاصه‌ی طراحی و رنگ‌ها.

## انتشار رایگان
1. در Netlify (Drop) یا GitHub Pages ثبت‌نام کن و پوشه‌ی پروژه را آپلود کن تا لینک بگیری. مراحل را قبل از اقدام از سایت رسمی هم چک کن.
2. اپ فقط روی لینک امن (https) درست کار می‌کند. `index.html` را با دو بار کلیک روی کامپیوتر باز نکن؛ از لینک منتشرشده استفاده کن.
3. سایت را به یک حساب رایگان خودت وصل کن تا پاک نشود و بتوانی به‌روزش کنی.
4. لینک باید همیشه ثابت بماند. برای به‌روزرسانی، پروژه‌ی جدید را روی **همان سایت** منتشر کن، نه سایت تازه.

## نصب روی گوشی
- اندروید (Chrome): منوی ⋮ ← «Add to Home screen» یا «Install app».
- آیفون (Safari): دکمه‌ی Share ← «Add to Home Screen».

## چک‌لیست تست قبل از دادن به دیگران
لینک را روی گوشی باز کن ← نصبش کن ← اینترنت را قطع کن و ببین آفلاین باز می‌شود ← یک تغییر کوچک بده و ببین نوار «نسخه‌ی جدید آماده است» می‌آید.

## تغییر محتوا و به‌روزرسانی برای همه
1. فایل JSON را ویرایش کن. نمونه‌ی یک کارت: `{"id":"animal-cat","name":"گربه","image":"images/animals/cat.webp"}` (`id` را بعداً عوض نکن).
2. در `service-worker.js` عدد `CACHE_VERSION` را یکی بالا ببر (مثلاً `"v2"`). اگر تصویر یا فایل جدیدی اضافه کردی، مسیرش را در لیست `FILES` همان فایل هم بنویس.
3. پروژه را روی همان سایت دوباره منتشر کن. کاربران بعد از یک‌بار باز کردن اپ (با اینترنت) نسخه‌ی جدید را می‌گیرند.
- رنگ‌ها: بالای `style.css`. فونت: فایل را در `fonts/` بگذار و در CSS با `@font-face` معرفی کن.
- سختی بازی: `levels-config.json` (مثلاً `secondsPerPair` زمان هر جفت در حالت چالشی است).

## ساخت APK برای اندروید (بدون فروشگاه)
> من در چت فایل APK نساخته‌ام؛ این راهنما برای ساخت خودت است.
1. بعد از انتشار لینک، در `pwabuilder.com` آدرس را بزن و گزینه‌ی Android را انتخاب کن تا APK بسازد.
2. فایل **Keystore** و رمزش را جای امن نگه دار (برای به‌روزرسانی‌های بعدی لازم است) و یک نسخه‌ی پشتیبان هم کنار پوشه‌ی پروژه بگذار.
3. APK را با تلگرام یا لینک دانلود بفرست. گیرنده باید «نصب از منابع ناشناس» را فعال کند و بعد نصب کند.
4. آیفون فایل نصبی ندارد؛ فقط با Add to Home Screen از Safari نصب می‌شود.
5. برای تغییر محتوا، رنگ یا فونت به APK جدید نیازی نیست. فقط تغییر نام یا آیکون اپ روی گوشی به APK جدید نیاز دارد.

## نکته‌ها
- پیشرفت، رکوردها و تنظیمات با localStorage روی همان گوشی ذخیره می‌شوند و بین گوشی‌ها منتقل نمی‌شوند.
- لرزش روی آیفون کار نمی‌کند. صداها با کد ساخته می‌شوند.
